### 4️⃣ [App Store UI — App Showcase](https://beautiful-sorbet-0ceabe.netlify.app/)
A responsive App Store UI that lists apps from a JSON dataset, supports live search, app details with install functionality (saved to localStorage), review charts, sorting, and a “My Installation” page.

**Tech Stack:** HTML, CSS (Vanilla / Tailwind / DaisyUI), JavaScript (Vanilla), Recharts  
**Main Features:** Responsive layout, JSON-driven app data (12–20 items), Home + All Apps + App Details pages, live search, install/uninstall (localStorage), install toast, review chart, sort by downloads, loading animations, custom 404.  
**Live Demo:** https://beautiful-sorbet-0ceabe.netlify.app/  
**Notes:** Includes required functionality such as active nav routing, install button state, “Show All” for apps, and persistent installs in localStorage.
